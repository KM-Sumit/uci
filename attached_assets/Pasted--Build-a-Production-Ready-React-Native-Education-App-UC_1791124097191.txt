# Build a Production-Ready React Native Education App — UCI

You are a senior React Native + backend engineer and UI/UX designer.

Build a complete, production-ready mobile education application named:

**UCI — Government Exam Preparation**

UCI is a coaching institute that helps students prepare for government competitive examinations.

The application must be professionally designed and should feel like a modern premium coaching/education application similar in quality and UX to leading Indian coaching apps.

Do NOT create a simple demo or prototype.

Build a properly structured application with real authentication, real database operations, admin management, secure API communication, dynamic content, proper validation, loading states, error handling, and production-ready architecture.

# 15. AI TEST GENERATION

Admin should be able to generate tests using AI.

Admin enters:

```text
Exam:
SSC CGL

Subject:
Quantitative Aptitude

Topic:
Percentage

Number of Questions:
20

Difficulty:
Medium

Language:
English/Hindi

Question Type:
MCQ
```

Backend sends a structured request to OpenAI.

The AI must generate questions in structured JSON.

Example:

```json
{
  "title": "Percentage Test",
  "questions": [
    {
      "question": "What is 20% of 500?",
      "options": [
        "50",
        "100",
        "150",
        "200"
      ],
      "correctAnswer": 1,
      "explanation": "20% of 500 is 100."
    }
  ]
}
```

IMPORTANT:

Never blindly trust AI output.

Backend must:

1. Validate JSON.
2. Validate number of questions.
3. Validate all options.
4. Validate correct answer.
5. Remove malformed questions.
6. Store validated questions in PostgreSQL.
7. Return test ID.

If OpenAI produces invalid output, handle the error gracefully.
